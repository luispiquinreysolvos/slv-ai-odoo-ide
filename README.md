HERRAMIENTAS IA DE SOLVOS PARA USO EN ODOO
==========================================

Scripts para instalar OpenCode y generar automáticamente su configuración en Windows y Linux. Incluyen tres perfiles de agentes, cinco servidores MCP, el plugin Ponytail y skills para desarrollo en Odoo, además de configurar la ruta de acceso a los proyectos y respaldar la configuración anterior.
